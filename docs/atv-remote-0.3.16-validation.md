# ATV Remote 0.3.16 top indicators and expanded remote

Version 0.3.16, build 19, moves the connection indicators directly beneath the room selector. Apple TV and Samsung sit side by side in equal-width cells. Each name is followed by its device icon and green/gray dot; retry, PIN and trust actions appear below their corresponding label only when needed. Long names truncate on one line and VoiceOver keeps the full device name/type/state. One selected TV uses the available width; no selection hides the band. The former bottom indicator rows are removed.

**Expanded Apple TV remote** is a new saved layout option. Both D-pad and touchpad use a square surface across the available content width, retaining the screen’s 18-point side margins. Directional and OK controls scale with the surface while remaining inside it. Back/Home, Play/Pause and Mute grow from 64 to 76 points. Horizontal gaps grow from 20 to 36 points; vertical gaps grow from 16 to 24 points. The continuous volume rocker is 76×176 points and the pad-to-buttons gap is 32 points. Standard and the regular Apple TV remote remain available, including the previous `stackedVolume` migration and saved pad preference. The existing scroll fallback applies when larger content does not fit.

Changes are limited to RemoteScreen, RemoteLayout, the existing layout UI test and the version generator. Navigation, Samsung volume routing, connection actions, pairing/room assignments, power, artwork cache, sharing and shortcuts remain unchanged. The existing UI test now checks expanded width/spacing for both pad modes, layout persistence and return to Standard. It is compiled, not executed.
