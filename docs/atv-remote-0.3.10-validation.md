# ATV Remote 0.3.10 Xfinity flick and room header

Version 0.3.10, build 13, addresses the reported incomplete Xfinity dismissal with one faster, full-height swipe. It replaces the top native room Picker label with an explicit single-line Menu label so **Living Room** can fit beside the gear and Shortcuts button.

## Changes and reviewed limits

The Xfinity gesture now presses at (500, 1000), sends twelve upward holds at 16 ms intervals through (500, 0), waits another 16 ms, then releases at the same endpoint. The whole movement reaches the top before release. The requested wait budget is 208 ms; actual transport and validation awaits can add time. The previous drag traveled from y = 850 to 150 with a 320 ms wait budget. This is gesture tuning based on the user's report, not a verified tvOS dismissal threshold. [Primary-source follow-up audit](atv-remote-xfinity-shortcut-audit.md).

The preset keeps the centered-Xfinity-card confirmation, one press/gesture per confirmation, original TV/session checks before and after every await, and original-touch cleanup on cancellation/error. It never automatically repeats the gesture, which could dismiss another card after the first succeeds. Back, wait, and exact Xfinity relaunch follow only a completed gesture. No vendor transport, driver credentials, targeted app-kill API, or automatic reconnection was changed.

The room Menu wraps the original room-selection Picker binding. Its explicit selected-name Text uses one line, up to 20% scaling, then tail truncation for long names, with a fixed 12-point chevron. VoiceOver keeps the full name in its value. Gear and Shortcuts preserve their 44-point controls, with a spacer between them. Existing room reselection no-op behavior and both saved volume layouts remain. Source review found no blocking issue; actual header rendering still needs an iPhone check.
