# ATV Remote 0.3.9 saved remote layouts

Version 0.3.9, build 12, adds **gear → Remote layout** with **Standard** and **Stacked volume**. Standard preserves the horizontal − / mute / + row. Stacked volume places + above − beside the navigation pad or touchpad, with mute underneath. The preference saves per iPhone, defaults to Standard, and applies across room changes and app relaunches.

## Implementation and review

`RemoteLayout` is a String-backed enum shared by Settings and the main screen through `@AppStorage` at `RoomRemote.remoteLayout.v1`. Changing it only changes presentation. It writes no TV/room registry or credentials, invokes no connection/selection action, and is not included in encrypted setup sharing. Existing disconnect intent, same-selection guards, pairing identities, and room assignments remain unchanged.

The stacked side arrangement uses a 228-point navigation surface, 16-point gap, and 72-point volume column. Horizontal ViewThatFits falls back to a below-pad column when 316 points are unavailable inside the screen margins. Standard emits its original volume row; stacked emits its column once. The existing vertical ViewThatFits keeps the remote non-scrolling when it fits, with size-based scrolling for smaller spaces or larger text. Symbols use a fixed 22-point font inside buttons with 48-point minimum height to keep the mute icon within the narrow column; captions remain Dynamic Type.

Volume and mute still explicitly route to the selected Samsung, independently of Apple TV navigation. The extracted navigation-surface view preserves the directional/touchpad gesture code and stale-device cancellation. Settings retains the current room heading, aligned TV menus, Disconnect / Connect, and shared-stack Back navigation. A source review found no remaining layout/routing issue; actual rendering is not established by that review.
