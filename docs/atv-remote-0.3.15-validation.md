# ATV Remote 0.3.15 remote layout, power and thumbnails

Version 0.3.15, build 18, remembers D-pad/touchpad on this iPhone and increases the gap below the pad to 24 points. **Apple TV remote** replaces Stacked with the pictured Siri Remote arrangement: Back/Home above Play/Pause and Mute on the left, with a continuous vertical +/− rocker on the right and Power above the pad. The old stored `stackedVolume` value is retained for migration. Standard remains available. All volume/mute commands still target the selected Samsung; navigation and Home keep their existing routing and app-grid behavior. The alternative D-pad fits inside its 200-point surface with 52-point directional controls and a 64-point OK button. Connection icons and dots are unchanged.

Power has compact per-TV On/Off controls and a Samsung setup gear. On without a MAC opens that saved TV’s editor. With a saved MAC it retains the existing one-shot directed network wake and request cancellation. Samsung Off sends the existing single power-button toggle while connected; it does not have a discrete-off acknowledgement. The large setup row and helper paragraph are removed. Apple On/Off retain wake/sleep. [Power source audit and MAC findings](atv-remote-power-simplification-audit.md).

Every installed app row has a thumbnail tile. Verified App Store artwork is cached locally; built-in Apple apps and missing exact metadata use fallback symbols. Identity is exact bundle ID plus country, with bounded HTTPS metadata/image requests, downsampling, shared flights and cancellation. Disk/memory caching is bounded to 128 entries and 20 MiB; positive artwork refreshes after 30 days. App launches, installed rows and per-TV stars remain independent of artwork. No TV identities or credentials go to Apple. The API artwork/badge distribution conditions remain documented for future publication review. [Artwork/cache audit](atv-remote-app-artwork-audit.md).

All **181 actual-source offline Mac XCTest cases passed with zero failures**, including ten new artwork/cache cases. All 34 actual source/test symlink inputs match the final frozen manifest before and after execution. Tests use injected network loaders with real ImageIO decoding and disk-cache processing. They cover exact identity, endpoint/response gates, malformed metadata, fresh disk reuse without network, negative expiry, shared request cancellation and cache bounds. [Results](../audit/reproductions/atv-remote-0.3.15-core-tests.json), [test log](../audit/reproductions/atv-remote-0.3.15-core-tests.log).

Final native iOS 27 build-for-testing passed in 12.63 seconds. All 48 app/test/project/Info inputs remained unchanged, and all eight UI methods were verified in the compiled test bundle. The existing layout test now checks the alternative geometry, 24-point gap and both pad preferences across relaunches. No simulator boot or UI test execution occurred. Earlier attempts retain the Swift 6 test-capture failure and the test-fixture change; the final proof uses the corrected, unchanged source.
