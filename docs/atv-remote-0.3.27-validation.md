# ATV Remote 0.3.27 temporary wake feedback

Version 0.3.27, build 30, clears a Samsung wake confirmation three seconds after successful request submission. It uses a cancellable task with a separate request identity, so a canceled or older expiry cannot clear a newer confirmation. Another wake attempt clears the prior notice; Samsung selection/setup/cancellation and background changes also clear it. Shared diagnostic feedback is removed only if it still equals the expiring confirmation, leaving newer connection/command feedback intact. Errors remain persistent.

The success text is now a noninteractive bottom overlay in Power rather than an inserted List row. It neither changes the list height nor moves its controls when it appears or expires. The power symbol and progress spinner share a fixed 22-point slot to prevent a width change during the busy transition. No wake packet, connection, off-command or status-observation behavior was changed.

The unsigned arm64 iPhoneOS archive and native simulator test build passed. All 15 existing UI cases compiled; no new XCTest cases were written or run for this reversible UI change, and unit suites were not rerun. An actual native dark-mode smoke run used a DEBUG-only local confirmation fixture with established synthetic sessions. It exercised the production banner/timer without sending a datagram or any TV command. Before/visible/expired screenshots confirmed the notice appears and disappears; recognized room headers and On/Off labels retained their normalized positions within 0.001. All three captures were visually reviewed. This verifies layout and expiry, not device frame rate or physical wake behavior.
