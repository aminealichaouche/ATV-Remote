# ATV Remote app artwork and cache audit

Version 0.3.15 adds a 44-point thumbnail beside every installed app name. Downloaded apps use verified public App Store artwork when available. Included Apple apps have distinct local symbol tiles; an app without an exact catalog match uses a neutral tile. Artwork may differ from the tvOS icon. The app does not extract images directly from Apple TV or guess matches from names.

Companion remains the source of installed apps and launch identifiers. Artwork never creates a launchable row or modifies per-TV stars. Cache identity includes the exact case-sensitive bundle ID, locale country, catalog origin and schema version in a SHA-256 filename. The lookup result must be software with the same bundle ID and a validated store/image URL. [Apple lookup documentation](https://developer.apple.com/library/archive/documentation/AudioVideo/Conceptual/iTuneSearchAPI/LookupExamples.html).

The store runs outside MainActor. It uses a cookie-free ephemeral URLSession and restricts HTTPS lookup to itunes.apple.com/lookup and image downloads to numbered Apple mzstatic image hosts. Redirects and final responses receive the same checks. HTTP status, MIME and declared length must pass; streamed data stops at 256 KiB for metadata or 2 MiB for an image. Requests have 12-second request and 15-second resource timeouts. ImageIO validates one PNG/JPEG/WebP frame, bounded dimensions and pixel count, downsamples to 160 pixels, and re-encodes a PNG no larger than 256 KiB. Cache reads repeat image validation.

Local Caches/ATVAppArtwork-v1 storage and memory are bounded to 128 entries and 20 MiB. Metadata writes and image writes are atomic; LRU eviction removes old entries. Positive images refresh after 30 days, missing metadata retries after 24 hours, and transient errors back off for 15 minutes. A valid stale image can display immediately for up to 180 days while refresh runs. Concurrent matching rows share a request; canceling one retains other waiters, and canceling all removes that flight. Generation IDs prevent an old flight from clearing its replacement. There are two concurrent loads and metadata starts are paced 3.2 seconds apart, within Apple's documented approximate lookup budget. [Apple Search API guidance](https://performance-partners.apple.com/search-api).

Only app bundle ID and country are sent to Apple. TV names, IP/MAC addresses, pairing credentials and stars are not sent. Included Apple IDs skip lookup. DEBUG UI-test fixtures suppress public artwork requests. Images are decorative for VoiceOver; existing app-name launch and separate star actions remain. Verified metadata adds a separate App Store info link. Artwork errors leave remote commands and app actions available.

Independent source review found and fixed a cancellation handoff that could lose a concurrency slot, then verified the final limiter and flight cleanup. Cache access dates and UI retention were also bounded. Ten offline tests cover identity, response gates, malformed metadata, real ImageIO normalization, shared requests, disk reuse without network, negative expiry, cancellation and cache size. Actual execution outcomes are recorded in the [release validation](atv-remote-0.3.15-validation.md). Injected loaders exercise cache behavior, not the live URLSession delegate; real catalog/CDN behavior and iPhone rendering still need testing.

Apple's published artwork conditions describe a nearby approved App Store badge, and its badge guidelines have their own license scope. The compact App Store link in this test build does not assert that every badge or distribution condition has been satisfied. Those requirements remain a distribution review item before publication. The cited no-cache condition applies to song/music-video previews, which this app does not use. [API artwork conditions](https://developer.apple.com/library/archive/documentation/AudioVideo/Conceptual/iTuneSearchAPI/index.html), [badge guidelines](https://developer.apple.com/app-store/marketing/guidelines/). No TestFlight or App Store publication occurred.
