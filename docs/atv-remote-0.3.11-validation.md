# ATV Remote 0.3.11 four-word transfer phrases

Version 0.3.11, build 14, displays four random words for each new encrypted setup transfer. Spaces, hyphens and capitalization differences are accepted on import. Both phones need 0.3.11 or later for new phrase files. Older files still unlock with their original long codes. [Sharing instructions](share-pairings.md).

## Implementation and review

The 7,772-word attributed EFF-derived dictionary is bundled in source. Four independent uniform CSPRNG choices use rejection sampling, preserve order and allow repeats. Canonical input accepts exactly four complete words and is bounded to 128 bytes. Four words supply 51.696 bits of entropy, below the previous code's 160 bits; fixed slow key derivation raises guessing cost. [Security and compatibility audit](atv-remote-transfer-phrase-audit.md).

New encrypted envelopes use version 2 with AES-GCM and CommonCrypto PBKDF2-HMAC-SHA256, exactly 600,000 iterations, a fresh 16-byte salt and a 32-byte key. The version/KDF/cost domain binds salt derivation and authentication. Unsupported metadata, downgrade attempts and malformed bounds reject before KDF work. Legacy v1 imports retain the exact original code/HKDF/AAD path. The decrypted room/pairing payload remains version 1, with existing identity and import policies.

TransferScreen encrypts and unlocks off the main actor. Cancellation is forwarded to its detached task; request UUID guards discard stale results before exporting a file or publishing a review. The synchronous KDF may finish after cancellation, but its result is discarded. Face ID/passcode authorization, sensitive phrase display, secure import field, local-only five-minute clipboard, encrypted-only sharing and explicit import approval remain. [Independent source review](../audit/reproductions/atv-remote-0.3.11-phrase-source-review.json).
