# ATV Remote 0.3.22 Home gestures and restart macros

Version 0.3.22, build 25, preserves single Home as a one-second Menu/Back hold to reach the Apple TV app grid. Home double-tap now sends the TV button's double-tap for the app switcher; holding Home sends the TV button's hold for Control Center. Samsung keeps its single Home key. Native recognizer dependencies prevent an extra single press after a double tap or hold. Pending recognition captures device type, identity and connection epoch; store dispatch checks the capture again. VoiceOver has separate Home, App switcher and Control Center actions. No vendor code or persisted/shared schema changes.

Xfinity restart runs directly after one tap. The prior hover/card-confirmation and card-movement controls are removed. **Restart current app** appears immediately below it, opens an installed-app chooser with a native back button, and uses the same macro for the exact chosen ID. Companion cannot reliably identify the foreground app: a macro can dismiss the focused card, but cannot reliably recover an unknown app ID to reopen it. Playing-media or last-launched metadata is not used as foreground identity. [Primary-source audit](atv-remote-xfinity-shortcut-audit.md).

Every run reserves its original selected Apple TV/session and checks a fresh installed-app list, target syntax and available swipe support before effects. It launches the target, opens the switcher, sends one upward flick, exits with Back and relaunches the same ID. It stops on cancellation, sheet closure, backgrounding, selection/session changes or failure. Only an original-sender release cleans up a partially sent touch. There is no swipe retry, command replay or automatic resumption after connection refresh.

The macro assumes the newly launched app is the focused switcher card. That is not proven by the protocol or delays, and another controller or overlay can change focus. Success reports **[app] restart sent** below both shortcut controls, rather than verified process termination. Physical TV gesture, focus, dismissal and relaunch testing were not performed from this workspace.

All 185 hosted native iOS 27 unit tests passed with zero failures against the final frozen sources. The seven added cases cover distinct Home mappings, stale capture identity, a one-pass restart, an exact generic target, missing targets, and a failed preparation observer. Existing cancellation, error and original-touch cleanup cases also pass. Initial UI runs failed on an inactive Home binding and an overridden success identifier. The activity flag now publishes changes so a connected Home button refreshes when foregrounding without a connection-state update. The diagnostics container no longer overrides child identifiers. The test allows adjacent list rows to share an edge. Initial, diagnostic and gesture-trace failure logs remain in `audit/reproductions`; temporary gesture tracing was removed before the final archive. The final passing run uses the corrected app/test sources. Simulator fixtures use synthetic identities, hold auto-connection and do not control user televisions or use pairing credentials.

The arm64 unsigned iPhoneOS archive and IPA passed verification. All 12 packaged files byte-match the archive and all 61 frozen inputs remain unchanged. DEBUG fixtures/test types and artwork types are absent from the executable. Bundle ID `local.roomremote.ios`, display name ATV Remote and minimum iOS 27 remain.
