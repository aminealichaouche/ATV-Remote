# ATV Remote 0.3.32 Manage TV and complete setup sharing

Version 0.3.32, build 35, replaces Power-on setup with Manage TV. Saved Samsung cards and the Power gear open editable labelled IP and MAC fields; saved Apple TVs get IP editing. Drafts start with saved values once and survive scanner return. Every scanner presentation captures a fresh IP/MAC snapshot and has a new view identity, preventing an earlier sheet state from restoring the old IP. Scanning can update both addresses. Save validates both before changing either, persists synchronously on the same identity, and invalidates an old selected-IP connection before reconnecting under existing manual-disconnect and pairing/certificate rules. It does not move rooms, reset stars or delete pairing keys. Blank edits cannot erase an existing MAC; explicit Remove saved MAC remains. On reads the latest saved IP and MAC without restarting. The actual Samsung wake protocol is unchanged.

Share defaults now include selected TV profiles (IP/MAC/name), Room Group Pairings, authenticated Saved TV access, Starred apps and Remote layout & pad. The receiver reviews per-TV star counts and the layout/pad choice and can decline them independently. Imported stars replace the exact list for selected matching Apple TVs, including clearing a sender's empty list. Other TVs stay unchanged. Unknown apps remain saved preferences but are hidden from the installed-app list. Replacement checks the final global limit atomically, independent of dictionary order. Existing TV credentials, local profile metadata and configured rooms retain the prior conflict/preview rules. A fresh install's sole unused Living Room is replaced by the incoming Living Room, avoiding an unnecessary shared suffix; configured rooms are preserved. Auto mode, current navigation selection and running sessions remain local.

New shares with stars or remote preferences use payload version 2; version 1 transfers remain readable without clearing local preferences. Both phones need 0.3.32 for full setup transfers. Unchecking both new options produces the legacy payload version. Encryption remains the same authenticated AES-GCM envelope, four-word phrase and PBKDF2-SHA256 settings. The complete unlocked file is validated before filtering, including skipped stars. Star references must identify selected Apple TVs and have valid bounded app IDs; per-TV/global limits remain 256/1024. Remote layout decodes only known enum cases. Import sends no TV commands and applies preference changes only after registry commit.

All **98 targeted native iOS 27 tests passed with zero failures**: thirteen new shared-setup/network-edit cases, 45 registry cases, 23 encrypted-transfer cases, nine selective-import cases and eight app-library cases. They cover invalid IP/MAC atomicity, stable identity/rooms/stars, exact star replacement/clearing, omitted/conflicted TV handling, absent-app filtering, global-limit rebalancing and atomic rejection, old/new encrypted payloads, independent opt-outs and room preservation/idempotence. Other native test classes were not rerun. [Native report](../audit/reproductions/atv-remote-0.3.32-native-unit-tests.json).

Four native simulator UI cases passed with zero failures: editing/scanning IP+MAC and immediate constructed wake target followed by cold-relaunch persistence; saved/scanned/re-saved MAC use; blank Save and explicit removal; review/import of stars and remote appearance, live geometry/pad update and cold-relaunch reexport with exact star count and appearance. Synthetic profiles are manually disconnected, the wake recorder replaces UDP and no TV credentials are exported or imported. Actual camera recognition, Wi-Fi wake, changed-IP TLS handshake, AirDrop and two physical iPhones remain unverified. Manage TV and reexport screenshots were exported and visually reviewed. All 21 UI methods compiled; 17 were not rerun. [UI report](../audit/reproductions/atv-remote-0.3.32-ui-runtime.json), [combined validation](../audit/reproductions/atv-remote-0.3.32-validation.json).

The unsigned arm64 iPhoneOS archive passed, all 12 IPA files byte-match it, and ZIP integrity passed. Manage TV and transfer objects are linked. 68 source/resource/script and 56 native compile inputs stayed frozen through final validation. DEBUG fixtures are absent. Bundle ID `local.roomremote.ios`, display name ATV Remote and minimum iOS 27 remain.
