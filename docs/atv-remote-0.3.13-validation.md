# ATV Remote 0.3.13 live camera text scan

Version 0.3.13, build 16, adds a camera text button beside both Samsung IP and MAC fields, and beside a saved TV’s power-on MAC field. It reads live TV text using VisionKit, accumulates complete labeled addresses across the Network Status and About This TV menus, and opens a review step. Multiple candidates require a choice, with Wi-Fi and Ethernet labels preserved. Applying fills unsaved fields; pairing and saving remain separate. Existing-TV setup checks the selected target and blocks conflicting detected IPs. Names, room assignments and pairings remain unchanged by scanning.

Review removes the camera controller. Permission denial and unavailable devices retain manual entry; backgrounding clears drafts and invalidates callbacks. There is no QR decoding, still-photo capture, photo library access, image upload or transcript storage. The bounded parser rejects URLs, malformed/private-address failures, and known gateway/DNS/subnet/Bluetooth/remote-control labels without guessing unclear OCR characters. Camera recognition is conservative and needs a real iPhone check. See the [independent source audit](atv-remote-live-text-audit.md).

The corrected stacked volume layout is included: below Back/Home/Play, with mute centred on the left and + above − together on the right. Standard’s horizontal layout, saved layout preference, per-TV app stars, single-line room menu, Samsung wake, four-word encrypted transfers and the bundled Xfinity shortcut remain.

All **171 actual-source offline Mac XCTest cases passed with zero failures**, including 16 parser cases. All 31 production/test inputs match the frozen release before and after execution. [Core results](../audit/reproductions/atv-remote-0.3.13-core-tests.json), [test log](../audit/reproductions/atv-remote-0.3.13-core-tests.log).

Native iOS 27 build-for-testing passed. The app and eight UI methods compiled, including a camera-free fixture that checks adapter selection, draft application and no automatic pairing. The final incremental compile took 3.09 seconds after the initial 30.38-second compile. No simulator boot, UI execution, visual layout check, camera authorization, live OCR or physical TV interaction occurred. [Compile report](../audit/reproductions/atv-remote-0.3.13-ui-compile.json), [compile log](../audit/reproductions/atv-remote-0.3.13-ui-compile.log).

The unsigned arm64 iPhoneOS archive and IPA passed package checks. All 12 packaged files match the archive; all 54 frozen inputs and the final native compile inputs remain unchanged. Version/build, minimum iOS 27, stable bundle ID, camera usage description, valid ZIP, executable permission and unsigned code were verified. There is no photo-library permission, and DEBUG scan/reset/transfer fixtures are absent from the IPA. The compiled remote icon, official Shortcuts icon, exact 7,772-word transfer dictionary, wake action and Xfinity preset remain present. On your iPhone, open gear → Manage TVs → Samsung TV, tap the camera text icon beside IP or MAC, allow Camera access, and point at the TV’s displayed text. Tap Review addresses, choose its active connection’s MAC, check the values, and apply. Finish with Add and pair or Save. Test permission recovery, scanning both menus, Cancel, backgrounding, target mismatch and the stacked volume arrangement using the [installation checklist](install-and-test.md).
