# ATV Remote 0.3.7 Samsung power-on

Version 0.3.7, build 10, adds **Power → Turn on Samsung TV** with per-TV MAC setup. The action can run while that Samsung's remote connection is offline. **Power-on setup** is available from Power and Manage TVs, with native back navigation; new Samsung setup also accepts an optional wake MAC.

The user must enable **Power On with Mobile**, enter the active Wi-Fi/Ethernet MAC, keep the TV plugged in, and use the same local IPv4 subnet. [Primary-source wake audit and setup](atv-remote-samsung-wake-audit.md), [installation instructions](install-and-test.md).

## Implementation and limits

- The saved Samsung's immutable ID, private IPv4 address, normalized MAC, and selection epoch scope each request. The packet is exactly six `FF` bytes plus sixteen copies of the six-byte MAC: 102 bytes sent once over UDP port 9. No `KEY_POWER` toggle is used for wake, and there is no broadcast fallback, cloud service, retry loop, or new entitlement.
- Before opening a socket, the sender reads active local IPv4 interfaces and actual contiguous /1–/30 masks. It rejects self/network/directed-broadcast destinations, including boundaries on /25 and /26 networks and overlapping interface ranges. It binds a matching local source and prohibits cellular and peer-to-peer. IPv6 and routed/VPN-only wake are unsupported. The existing Samsung address parser still conservatively rejects hosts ending in `.255`, including some otherwise valid /23 hosts.
- Only one send owns the Samsung command slot. A UUID gate prevents repeated ready callbacks from sending twice and prevents stale completions from clearing a newer request. The five-second transport timeout and cancellation close the socket. Selection changes, backgrounding, captured-panel dismissal, and edited wake metadata cancel pending work. Already delivered packets cannot be undone.
- **Wake request sent** means submission to the local network stack, not that the screen is on. UDP supplies no wake acknowledgement. Connection dots still depend on the existing certificate-pinned, TV-authorized WebSocket connection. The user taps Connect after startup when needed. Existing power toggle and Apple TV controls remain separate.
- `wakeMACAddress` is optional profile metadata. Older profiles decode with nil; validated new metadata can travel in existing encrypted version 1 setup files. Imports reusing an existing TV preserve its saved MAC. Editing MACs, room changes, pairing refresh, and recovery preserve IDs, room assignments, stars, tokens, and pins. The setter publishes only after an atomic registry save succeeds.

Manual entry avoids adopting the upstream metadata endpoint's TLS verification bypass or guessing the active Ethernet MAC from a field named `wifiMac`. [Audit](atv-remote-samsung-wake-audit.md). Unicast delivery depends on standby networking and address resolution; test immediately after off and after extended standby on each TV. No physical wake compatibility is claimed for the user's friendly “S95BD” or “S60” names without those tests.
